## Datos abiertos

El directorio [`open-data/`](open-data/) trae un pack abierto de datos de **investigacion abierta (OpenAlex)** (fuente publica, sin clave de API).

```bash
python scripts/fetch_open_data.py   # regenera el pack
```

Ver [`open-data/README.md`](open-data/README.md) para fuente y licencia.
